This repository follows Andrej Karpathy's **[makemore](https://github.com/karpathy/makemore)** series on YouTube, building character-level language models from scratch in PyTorch.

### Progress & Implementations
* **v1: Bigram Model** – classical counting/frequency tables.
* **v2: Bigram Model** - single-layer neural network with gradient based optimization.
* **v3: Multilayer Perceptron (MLP)** – Implemented Bengio et al. (2003) architecture using word embeddings and hidden layers.
